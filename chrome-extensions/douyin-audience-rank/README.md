# 抖音观众榜单助手

Manifest V3 Chrome 扩展。使用当前抖音登录状态读取：

- 昨日评论榜：`comment_cnt + 1d`
- 最近一场观看榜：`watch_duration + last_live`

接口请求不携带 `anchorID`。正常数据会在读取完成后自动上传到 ERP；日期、空榜或结果过期时会直接阻止上传。

## 安装和更新

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择目录 `chrome-extensions/douyin-audience-rank`。

代码更新后，在扩展管理页点击本扩展的“重新加载”。当前版本为 `3.0.0`。

## 系统连接

ERP 地址和上传密钥已内置，员工安装后无需填写或保存任何配置。插件打开时会自动检查系统连接：

- 显示“系统连接正常”后可以读取、上传。
- 本地服务未启动时，显示连接失败并提供“重新检查”。
- 服务端密钥与插件不一致时，统一提示“插件版本已过期，请更新插件”。

当前本地服务地址为 `http://127.0.0.1:8080`。

## 日常操作

1. 在非观众分析页面点击插件图标，选择“打开观众分析页”。
2. 在观众分析页面点击插件图标，网页右侧会显示悬浮窗。
3. 悬浮窗可拖动、收起或关闭，并会记住上次位置。
4. 点击“读取并同步”，插件会读取双榜、校验数据并自动上传。
5. 日期或榜单异常时只能重新读取，不能绕过校验上传。

上传后可能出现以下结果：

- 绿色“上传成功”：ERP 已保存榜单并匹配到唯一直播间。
- 琥珀色“已保存，但直播间未匹配”：数据已保存，需要进入 ERP 确认直播间归属。
- 琥珀色“已经上传过”：ERP 没有生成重复数据。

## 防误操作规则

- 未识别到直播间时不能读取或上传，需先刷新抖音观众分析页。
- 重新读取期间会保留原结果；只有新结果读取和校验成功后才会替换。
- 任一榜单为空时禁止上传，必须重新读取。
- 评论榜日期必须是上海时区的“昨日”，否则禁止上传。
- 读取结果超过 30 分钟后禁止上传，必须重新读取。
- 上传中会锁定按钮，成功或判定重复后同一批数据不能再次提交。
- 关闭悬浮窗后，本次结果会保存在 `chrome.storage.session`；关闭 Chrome 后会自动清除。

## 技术信息

技术人员需要排查抖音接口变化时，可在悬浮窗底部展开“技术信息”：

- “复制 JSON”复制最近一次抖音接口原始响应。
- “导出 JSON”保存最近一次抖音接口原始响应。

原始 JSON 不包含 ERP 地址和上传密钥，也不会自动上传。若悬浮窗关闭后原始 JSON 因存储容量未被恢复，可重新读取一次再导出。

## ERP 接口约定

扩展调用以下接口，并通过 `X-Audience-Upload-Key` 请求头传递上传密钥：

```text
GET  {ERP地址}/open-api/douyin/audience-rank/ping
POST {ERP地址}/open-api/douyin/audience-rank/import
```

上传体：

```json
{
  "roomName": "直播间名称",
  "capturedAt": 1787472000000,
  "commentDataDate": "2026.08.22",
  "watchDataDate": "2026.08.23",
  "commentRanks": [],
  "watchRanks": []
}
```

榜单公共字段为 `rank`、`nickname`、`secUid`、`isFollower`、`isFollowing`、`payLevel`、`payIconUrl`。评论榜另有 `commentCount`，观看榜另有 `watchSeconds`。

成功响应兼容常见的 `{ "code": 200, "msg": "...", "data": {} }`。导入结果建议返回：

```json
{
  "duplicate": false,
  "roomMatchStatus": "MATCHED",
  "matchedRoomName": "直播间名称"
}
```

`roomMatchStatus` 支持：

- `MATCHED`：唯一匹配，插件显示绿色成功。
- `UNMATCHED`：没有匹配，插件提示到 ERP 处理。
- `AMBIGUOUS`：存在多个候选直播间，插件提示到 ERP 确认。

如果导入接口不返回匹配状态，插件会按“已保存、待 ERP 检查”处理，不会错误显示完整成功。

## 上线配置

上线前由开发人员集中修改，员工端不提供配置入口：

1. 修改 `config.js` 中的 ERP 地址和上传密钥。
2. 将 `manifest.json` 的 `host_permissions` 中本地地址替换为线上 ERP 地址。
3. 提升 `manifest.json` 版本号并重新分发插件。

服务端更换密钥后，旧插件会自动失效并提示更新。不要将上传密钥写入说明、截图或聊天记录。

## 权限说明

- `activeTab`、`scripting`：识别目标页、切换悬浮窗并在当前观众分析页请求抖音同源接口。
- `storage`：保存本次会话的读取结果和悬浮窗位置。
- `https://anchor.douyin.com/*`：访问抖音直播服务平台。
- `http://127.0.0.1:8080/*`：访问当前本地 ERP 服务；上线时替换为线上地址。

扩展不读取、保存或上传 Cookie。抖音榜单请求由目标页面使用当前登录状态发起。

## 常见问题

- 提示“请打开观众分析页”：点击“前往观众分析”。
- 提示“未识别到直播间”：等待抖音页面加载完成并刷新，再重新打开插件。
- 提示抖音登录可能失效：重新登录抖音直播服务平台并刷新页面。
- 提示“插件版本已过期”：从管理员处获取新版插件，并在扩展管理页重新加载。
- 提示系统连接失败：确认本地 Java 服务已经启动，再点击“重新检查”。
- 提示抖音接口数据可能变化：展开“技术信息”导出 JSON，交给技术人员检查。
