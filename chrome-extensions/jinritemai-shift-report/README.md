# 巨量百应直播数据采集 V2

插件只做三件事：从当前巨量百应直播详情页读取 DOM、让员工确认五项累计数据、上传到鑫客 ERP。

## 数据范围

- 直播间名称
- 直播开始时间
- 累计曝光人数
- 累计观看人数
- 累计互动人数
- 累计新增粉丝
- 累计成交人数

插件不读取排班、不让员工选择班次、不自动创建系统直播间，也不监听巨量百应接口。班次匹配、直播间别名和各主播差额全部由服务器处理。

## 使用

1. 打开 `chrome://extensions/`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 打开巨量百应某一场直播的详情页。
4. 点击橙色悬浮球，再点击“读取数据”。
5. 核对五项数据后点击“确认上传”。

若直播间改名或没有匹配到排班，数据仍会保存，并进入系统“数据上报”页面等待管理员处理。
