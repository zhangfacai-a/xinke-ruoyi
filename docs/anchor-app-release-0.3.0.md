# 主播工作台 0.3.0 交付与更新

## 使用

1. 在旧版 0.2.13 点击“检查更新”，确认下载并运行安装程序。安装保留百应登录目录。
2. 新版进入“上报工作台”，登录网站账号；若百应登录失效，再单独登录百应。
3. 默认读取最新场次。核对直播间名称、场次、所选主播后，点击“采集并预览本次上报”。
4. 确认区间和增量数据后提交。网站“主播数据上报”查询同一份记录，来源显示 App 上报。
5. 管理账号在“主播分配”中选择直播间、勾选用户并保存。普通主播只可上报自己在已分配直播间的数据。

采集时间用于自动上报结束时间，不能用当前累计数据回填过去的结束时间。漏报应走“上报记录 → 新增补录”。最后一条为人工区间时，App 从已确认区间接续并标记人工基线。

提交超时会保存受系统保护的待确认草稿。先点击“核对并重试原上报”，同一预览不会重复写入；不要立即换一个新预览重新提交。预览有效期为采集后5分钟，重试任务最长保留30分钟，过期后先核对服务器记录再放弃本地草稿。

## 后续发版

1. 改项目及安装脚本版本号，在 `xinke-ui` 运行 `npx vite build --config vite.anchor.config.js --mode desktop`。
2. 在仓库根目录运行 `./clients/anchor-metrics-probe/publish-update.ps1 -Notes '更新说明'`。
3. 网站管理员打开 `http://47.116.62.234/anchor-console/anchor-releases.html`，上传桌面安装包和 `clients/build/anchor-app-release/latest.json`。
4. 确认草稿版本和说明，点击发布。客户端从原更新地址检查新版。

签名私钥只留在发布电脑。网站验证清单签名和安装包 SHA-256，分片重复上传不重复追加内容。发布先安装包后清单，清单原子切换。

## 本次验证

- Java：区间计算、人工补录后的接续、并发与幂等、操作人与主播分离、名单冲突、用户范围和签名拒绝测试。
- 本地客户端：请求允许范围、采集字段校正、响应解析、业务界面构建、HTTPS 证书固定连接。
- 在线隔离场次：分配主播、预览、App上传、重复提交、过期拒绝、累计回退拒绝、人工区间接续、并发冲突、作废和审计。测试专用记录在结束后清理。
- 更新：通过网站管理接口上传签名安装包、重复分片验证、发布，再使用0.2.13更新器检查与下载校验。
- 实机升级：已从安装版0.2.13点击“新版0.3.0”，完成下载校验、安装和自动重启；安装版标题显示0.3.0，网站账号与百应登录状态保留，并重新采集齐9项指标和成交金额。
