# 主播工作台页面改版设计

本次交付为交互设计稿，不改线上页面和业务数据。用户已选择“聚焦上报”，并要求本次区间明细默认展开、显示上次数据作为参考。

## 页面主线

核对直播间和场次 → 选择实际上播主播 → 采集并预览 → 确认上报。

窗口顶部保留网站账号和百应连接状态。页面标题直接显示直播间名称，名称继续取 live_base_info.data.nickname。标题、场次 ID、秒级开播时间放入“场次详情”，不与直播间名称混用。

## 聚焦上报（推荐）

- 顶部：直播间名称、开播时间、最近采集时间、切换场次。
- 辅助累计条：成交金额、观看人数、成交人数、千川消耗横向排列，完整累计指标按需展开。
- 主要上报卡：主播选择、当天的上报起止时间、时长、区间预览集中展示。成交金额最突出，观看人数、成交人数、投流消耗次之。
- 区间明细默认展开：成交金额、观看人数、成交人数、投流消耗、新增粉丝、预售订单、进房率、转粉率、互动率（估算）、成交率，支持手动收起。
- 明细使用“指标 / 本次区间 / 上次已上报”三列对齐。上次参考取同一场次最近一条有效上报记录（可能属于其他主播），显示对应主播和起止时间，不随当前归属主播变化而改用该主播更早的记录。
- 上次参考读取记录中的实际区间指标；缺失显示“—”，合法0值显示0，比例按记录原有口径显示。不得用累计值或猜测值补齐历史明细。
- 当前设计稿只从截图获得上一条记录金额等摘要，其余历史指标显示“—”；实际页面使用服务端返回数据。
- 两次区间时长不同，仅作接续核对参考，不增加误导性的涨跌箭头或业绩好坏结论；上次参考不是服务端增量计算基线。
- 卡片底部：操作账号、预览状态、次要按钮“重新采集”、唯一主要按钮“确认上报”。
- 右侧辅助区：上次已上报的主播、结束时间、接续时间；最近两条记录。完整记录进入“上报记录”。
- 中小窗口右侧辅助区下移；窄窗口将累计条及指标网格换行。实际实现时不隐藏必要记录入口。

## 内容与数字

- 同一天只在页面说明日期，区间使用 HH:mm:ss；跨日区间分别显示日期。
- 金额固定两位小数并加千分位；人数使用整数；比例保留两位小数。
- 中文统一使用系统无衬线字体，金额和时间使用等宽数字。默认正文14px，辅助信息12px，直播间标题20–22px，主要金额28px，避免全页面字号同时放大。
- 白色工作区域、浅灰背景、深色正文；橙色用于当前导航、主要按钮和本次成交金额；绿色仅用于连接成功和操作成功。
- “本场累计”“本次区间数据”明确区分，不把累计值误标为当前主播的区间业绩。
- 原始记录时间按实际存储值展示，不为视觉效果改写历史区间。历史重叠等数据问题另行核实。

## 交互状态

1. 待采集：选择主播，显示开始时间；结束时间标“采集后确定”；主要按钮为“采集并预览”。
2. 采集中：显示阶段，例如读取直播间、采集指标、生成预览；防止重复操作。
3. 预览就绪：显示精确区间和时长；主要按钮为“确认上报”；“重新采集”为次要按钮。
4. 修改主播、切换场次、更新采集数据：按现有规则使旧预览失效，需重新生成预览。
5. 上报成功：显示成功及记录编号，更新已上报信息，提供“查看记录”；不会自动再次提交。
6. 缺少指标或登录失效：显示具体原因，分别提供“重新采集”“登录百应”“查看日志”。缺失值使用“—”，不当作0。
7. 预览过期或数据冲突：保留可读信息，明确要求重新采集预览。
8. 有待确认上报：优先显示“核对并重试原上报”，新提交继续禁用，保留幂等保护。
9. 未绑定系统直播间、未分配主播、网站未登录：在上报卡内解释并提供与当前账号权限匹配的入口。
10. 人工基线、首次上报：在区间附近保留业务提示，不隐藏已有必要确认。

## 其他页面风格

- 上报记录：默认只显示主播、区间、时长、成交金额、来源和操作；其余指标展开查看。筛选栏集中放置直播间、日期和主播。
- 主播分配：左侧直播间列表，中间已分配主播，侧面抽屉添加用户；保存前显示新增/移除差异，沿用服务端权限及名单冲突校验。
- 设置与更新：网站账号、百应账号、软件版本、运行日志分组展示。日志按采集/上报/登录/更新筛选，失败时可从工作台直接进入。

先落地主工作台视觉和内容重排，再按同一规范整理其他页面；采集、权限、签名更新和区间计算规则沿用现有实现。

## 安装、开机自启和帮助（用户补充）

这些为下一版验收要求，当前0.3.0安装脚本尚未包含桌面快捷方式和自启设置。

### 开机自启

- 安装界面增加“登录 Windows 后自动启动”，首次安装默认勾选；仅当前 Windows 用户生效，不需要管理员权限。
- App“设置与更新 → 启动设置”提供同一开关，读取系统实际配置，保存失败明确报错。通过系统启动快捷方式实现，取消时只移除本应用创建的快捷方式。
- 自动启动后进入系统托盘，不弹出百应页面、不抢占前台；登录失效时等用户打开再登录。托盘菜单提供“打开工作台”“退出”。
- 双击桌面图标正常显示主窗口；已运行时唤起现有窗口，避免多个实例同时读取登录目录或上报。
- 关闭按钮真正退出，最小化进入托盘；采集、提交、未保存内容继续沿用现有保护提示。
- 自启只启动软件，不自动确认或提交上报。
- 网站更新保留用户的自启选择，未出现新选项的旧版首次升级进入安装选项或采用明确默认值，之后升级不重新覆盖用户设置。
- 卸载移除应用创建的启动快捷方式；不修改其他应用的启动配置。

### 桌面图标

- 安装界面“创建桌面快捷方式”首次默认勾选，名称统一为“鑫客主播工作台”。
- 使用统一的“鑫”字品牌图标：橙底、浅色字，制作16/24/32/48/64/128/256尺寸ICO，应用EXE、窗口、托盘、安装及卸载入口保持一致。
- 桌面和开始菜单快捷方式指向固定安装路径；覆盖更新后继续有效且不产生重复图标。
- 升级保留用户已选任务；卸载移除安装器创建的快捷方式。
