# 鑫客主播工作台 0.3.1

## 交付内容

采用确认的“聚焦上报”页面。区间十项明细默认展开，与同一场次最近一条有效上报逐项对齐；保留主播、日期及精确区间，缺失值和合法零值分别展示。

本场累计缩为横向辅助条。主要操作按采集预览、确认提交分阶段，原有幂等、权限、人工基线及待确认草稿保护保留。

新增当前Windows用户的启动快捷方式设置、托盘运行、单实例唤起、桌面快捷方式、统一品牌图标及离线帮助。

本次验证中发现百应已登录但直接进入罗盘大屏返回st=10012；改为与官方入口一致的登录中转流程。经真实场次验证可恢复完整采集。

## 构建与整理

1. `scripts/build_anchor_desktop_assets.py` 生成多尺寸ICO及离线HTML帮助。
2. 在xinke-ui运行 `npx vite build --config vite.anchor.config.js --mode desktop`。
3. 运行 `clients/anchor-metrics-probe/publish-update.ps1` 构建并签名安装包。
4. 运行 `scripts/package_anchor_workbench.ps1` 在桌面生成分享文件夹和ZIP；文件按白名单整理，不复制本机配置或登录目录。

网站更新所需签名清单仍保存在clients/build/anchor-app-release，不混入发给普通用户的分享包。本次无需数据库迁移和服务端业务变更。
