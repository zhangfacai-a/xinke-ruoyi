# 主播工作台0.3.2：修复首次安装

0.3.1在InitializeWizard中展开{app}，普通首次安装会在安装目录初始化前中断。上次本机测试传入/TASKS参数，跳过该分支，没有覆盖普通安装流程。

修复：在任务选择页首次显示时恢复已有设置；静默安装通过PrepareToInstall补充执行。两个入口共用一次性保护，不在InitializeWizard引用{app}。覆盖安装明确取消自启或桌面图标时删除对应旧快捷方式，防止取消选项后残留。

增加与正式安装脚本共源的隔离安装回归：独立AppId、工作区独立安装目录，桌面、启动及开始菜单快捷方式重定向到测试目录，不修改真实用户安装信息。

回归场景：无旧版且不传/TASKS的首次安装（默认图标和自启）、覆盖安装保留关闭的自启设置、显式开启、显式取消。测试实际执行安装器并检查退出码及快捷方式结果。

2026-11-24验证结果：上述四项全部通过。最终分享包5个文件，ZIP完整性、逐文件SHA-256和更新清单RSA签名验证通过，大小44.04MiB。旧版桌面分享文件夹和ZIP已标记“旧版勿用”。

交付0.3.2桌面分享文件夹与ZIP，包含重新签名安装包、版本一致的离线帮助、快速开始、更新说明及SHA-256。0.3.1停止分发。
