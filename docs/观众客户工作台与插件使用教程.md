# 观众客户工作台与插件使用教程

这份教程给第一次使用的同事看。平时只需要记住两件事：

1. 用插件把抖音榜单同步到系统。
2. 在“观众客户”中领取客户、记录沟通结果。

> 普通员工不需要填写系统地址、密钥，也不需要处理技术设置。

## 一、每天怎么做

最短操作流程：

1. 登录抖音直播服务平台。
2. 打开“观众分析”页面。
3. 点击浏览器右上角的“观众客户同步”插件。
4. 点击“读取并同步”。
5. 看到“上传成功”后，进入公司系统的“观众客户”。
6. 在“今日工作”中点击“处理下一位”。
7. 填写沟通结果，点击“保存并下一位”。

## 二、第一次安装插件

插件一般由管理员提前安装。需要自己安装时，按下面操作：

1. 在 Chrome 地址栏输入 `chrome://extensions/`，按回车。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择管理员发给你的插件文件夹。
5. 安装完成后，把“观众客户同步”固定到浏览器右上角。

以后更新插件时，进入同一个页面，找到“观众客户同步”，点击“重新加载”。

## 三、用插件同步榜单

### 1. 打开正确页面

插件只能在抖音的“观众分析”页面读取数据：

`https://anchor.douyin.com/anchor/analyze/audience_rank?from=default`

如果当前页面不对：

1. 点击插件图标。
2. 点击“打开观众分析页”。
3. 等页面加载完成后，再点击一次插件图标。

在正确页面打开插件后，网页右侧会出现悬浮窗。悬浮窗可以拖动、收起和关闭，下次打开会记住位置。

### 2. 一键同步

1. 看一眼插件显示的直播间名称是否正确。
2. 确认底部显示“系统连接正常”。
3. 点击“读取并同步”。
4. 等待插件完成读取、检查和上传，不要连续点击。
5. 看到“上传成功”即可关闭悬浮窗。

插件会自动处理：

- 昨日评论榜；
- 最近一场观看榜；
- 两个榜单中的重复客户；
- 已经上传过的相同数据。

不需要再点第二次确认，也不需要自己填写日期。

### 3. 插件提示怎么看

| 插件提示 | 怎么处理 |
| --- | --- |
| 上传成功 | 数据已经进入系统，可以开始跟进 |
| 已经上传过 | 不用再传，系统不会生成重复数据 |
| 系统连接不可用 | 确认公司系统后端已启动，再点“重新检查” |
| 插件版本已过期 | 联系管理员获取新版插件 |
| 当前页面无法读取榜单 | 点击“打开观众分析页” |
| 未识别到直播间 | 等页面加载完成；仍不行就刷新页面后重试 |
| 评论榜日期尚未更新 | 插件会提醒但仍正常上传；需要新日期时可在 12:00 以后重新读取 |
| 榜单为空或数据已过期 | 点击“重新读取” |

评论榜日期提醒不会阻止上传。只有榜单为空、数据过期等情况被插件阻止时，才需要按提示刷新页面或重新读取。

“技术信息”只供管理员排查问题，普通员工不用打开。

## 四、观众客户工作台怎么用

进入公司系统，打开“直播运营 > 观众客户”。常用页面有四个：

| 页面 | 用途 | 谁使用 |
| --- | --- | --- |
| 今日工作 | 按优先顺序处理自己今天的客户 | 跟单人员 |
| 客户库 | 查找客户、订单和历史记录 | 跟单人员、管理人员 |
| 管理中心 | 查看团队进度和设置分配规则 | 管理人员 |
| 上传记录 | 查看插件每次上传的结果和明细 | 上传人员、管理人员 |

普通员工平时主要使用“今日工作”和“客户库”。

## 五、处理一个客户

### 1. 从“今日工作”开始

页面已经按优先程度排好顺序。最简单的做法：

1. 点击“处理下一位”。
2. 如果客户还没有负责人，点击“领取客户”或“加入我的跟进”。
3. 联系客户。
4. 选择本次“沟通结果”。
5. 按实际情况填写其他内容。
6. 点击“保存并下一位”。

“保存并下一位”会保存当前客户，并自动打开下一位客户，日常连续跟单时最省操作。

### 2. 沟通结果怎么选

| 实际情况 | 选择 |
| --- | --- |
| 电话、私信没有回复 | 未联系上 |
| 已经沟通，但还没有明确购买意向 | 已沟通 |
| 有购买意向，需要继续追踪 | 有意向 |
| 已经下单 | 已下单 |
| 确认没有继续跟进价值 | 无效客户 |

选择“已下单”后，必须填写“本次订单号”。

选择“无效客户”后，必须选择“无效原因”。

其他未结束的客户需要设置“下次跟进”。可以直接点“2 小时后”“明天”“3 天后”或“7 天后”。

### 3. 建议填写哪些内容

- “咨询型号”：客户咨询的商品型号，例如 W3。
- “本次沟通记录”：写清客户需求、顾虑和下一步。
- “意向程度”：按实际情况选择高、中、低。
- “联系电话、微信号”：取得联系方式后填写。
- “长期备注”：只写以后仍有用的信息，不要重复粘贴本次沟通内容。
- “设为重点客户”：只给确实需要优先处理的客户勾选。

填写后点击“保存”。需要继续处理队列时，点击“保存并下一位”。

## 六、领取人、主播和场控不要混淆

- **领取人**：现在负责联系这位客户的人，可以从系统全部用户中选择。
- **主播**：客户来源直播间所配置的主播。
- **场控**：客户来源直播间所配置的场控。

主播和场控由“直播间 / 店铺”的人员配置自动带出，普通跟单人员不用手工选择。

例如：客户来自“小鑫直播间”，直播间配置的主播是赵月月，场控是小王；客服小李领取客户后：

- 领取人是小李；
- 主播是赵月月；
- 场控是小王。

## 七、客户库怎么用

需要找以前的客户时，打开“客户库”。

1. 在搜索框输入昵称、电话、微信、型号或订单号。
2. 需要缩小范围时，选择直播间或领取人。
3. 还找不到时，点击“更多筛选”。
4. 点击客户所在行，打开客户档案。

常用快捷分类：

- “跟进中”：还需要继续联系；
- “重复到访”：最近不止一次出现在榜单；
- “高意向”：优先推进成交；
- “已下单”：已经产生订单；
- “观察中”：暂时没有进入正式跟进；
- “已结束”：已经结束的商机。

客户档案右上角有两个快捷按钮：

- 打开该客户的抖音主页；
- 复制客户的用户标识。

## 八、同一客户连续来几天怎么办

不用手工合并。

系统会识别同一位抖音用户：

- 第一次出现时建立客户档案；
- 以后再次出现时更新同一份档案；
- 累计到访天数、最近排名和最佳排名会继续更新；
- 以前填写的沟通记录、订单和负责人不会被覆盖；
- 每次到访都可以在“客户时间线”中查看。

如果已经结束的客户再次到访，页面会提示“客户再次到访”。确认需要继续联系时，点击“重新激活”。

## 九、上传记录怎么用

插件显示上传成功后，想确认数据是否进入系统，可以打开“上传记录”。

这里可以看到：

- 上传时间和直播间；
- 评论榜、观看榜的数据日期；
- 本次去重人数；
- 新增客户数和更新客户数；
- 直播间是否匹配成功。

点击一条记录右侧的“查看”，可以看到本批客户明细及其评论榜、观看榜排名。

正常情况显示“已匹配”。如果显示“未匹配”或“名称重复”，点击“处理”并联系管理员检查直播间资料。

## 十、管理中心（仅管理员）

普通员工可以跳过这一节。

管理员主要做两件事：

1. 在“执行看板”检查待领取、已逾期和同步异常。
2. 在“进客与分配规则”设置每个直播间的进客、自动分配和超时回收规则。

出现主播或场控为空时，应先检查“直播间 / 店铺”中的人员配置，不要把领取人当成主播或场控填写。

## 十一、常见问题

### 点击插件没有悬浮窗

先确认当前是抖音观众分析页。不是时，点击插件里的“打开观众分析页”。

### 显示系统连接不可用

先确认公司系统后端已经启动，再点击“重新检查”。仍然失败时，把提示截图发给管理员。

### 插件提示已经上传过

这是正常的防重复提示，不需要再次上传。可以到“上传记录”查看原记录。

### 上传成功，但今日工作没有新客户

先到“上传记录”查看：

- “新增客户”可能为 0，这表示本批都是以前出现过的客户；
- 客户可能在“观察中”，可以到客户库查看；
- 如果直播间未匹配，需要管理员先处理直播间资料。

### 找不到某位客户

到“客户库”搜索昵称。仍找不到时，清除筛选条件，再按直播间或上传批次查找。

### 主播或场控不对

主播和场控来自直播间配置。联系管理员修改“直播间 / 店铺”的人员配置。

### 页面提示有未保存修改

说明刚才填写的内容还没有保存。点击“保存”或“保存并下一位”后再关闭页面。

## 十二、一页速记

### 上传人员

`打开观众分析页 → 点击插件 → 读取并同步 → 看到上传成功`

### 跟单人员

`观众客户 → 今日工作 → 处理下一位 → 领取客户 → 选择沟通结果 → 填写下次跟进 → 保存并下一位`

### 遇到异常

`不要强行上传 → 按插件提示重新读取或刷新页面 → 仍有问题就截图联系管理员`
