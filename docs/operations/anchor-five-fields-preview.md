# 主播新版采集：第一步五项字段

2026-11-27 根据已登录百应直播大屏实际 `core_data` 请求、字段标签和响应单位核对：

- 直播间成交金额（不含异常交易）：响应 `data.pay_amt`，单位 `price`，原值为分。
- 新增粉丝数：`core_data` 中的 `follow_anchor_ucnt`，单位 `number`。
- 千川消耗：`stat_cost`，单位 `price`，原值为分。
- 预售订单数：`pay_deposit_pre_order_cnt`，单位 `number`。
- 预售定金金额：`presale_depay_deamt`，单位 `price`，原值为分。

App 继续监听百应自身生成并签名的指标请求，新增定金字段到现有配置修复逻辑。原九项可选指标加定金共十项，符合该页面最多十项的限制；成交金额由独立 `pay_amt` 返回。主要展示区改为这五项，其他既有采集值暂放完整指标。

采集、存储快照状态中保留原始数值，金额展示除以100。缺失值显示横线，明确返回0才显示0；`pay_amt` 缺失时不以 `pay_amt_all` 替代。页面动画拆分的数字和残留“万”字样不用于取值。

本步骤范围为采集、配置和展示。尚未执行旧主播数据作废、数据库新版改造、区间算法切换，也未发布网站自动更新。预售定金当前进入采集状态和展示，不宣称已进入旧版上报接口；后续新版上报结构需一并接入。
