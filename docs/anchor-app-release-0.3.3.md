# 主播工作台0.3.3：修复新电脑找不到工作台文件

## 原因

0.3.2设置PublishSingleFile，但工作台HTML、JS、CSS及帮助内容未设置ExcludeFromSingleFile=true。重新publish后这些内容被装入单文件EXE，安装器实际只复制EXE。WebView虚拟主机映射读取磁盘ui目录，因文件不存在返回ERR_FILE_NOT_FOUND。开发机旧安装目录残留页面掩盖了错误；0.3.2验证只检查安装退出码和快捷方式，漏检真正的安装文件与首次运行。

## 修复

- 工作台页面、图标、帮助和资源清单显式作为外置文件发布，CopyToPublishDirectory=Always。
- 发布脚本自动重建Vue页面、生成图标/帮助/文件SHA-256清单，在每次全新发布目录中执行dotnet publish。
- 打包前逐项检查HTML引用、CSS、JS及帮助哈希；缺失则停止打包。安装器通过预处理校验入口和清单，禁止不完整目录生成安装包。
- 安装回归的每个场景检查安装后文件及其实际内容，不再只依赖安装器退出码。
- App启动校验资源清单，发现缺失或损坏时使用原生可见页面解释原因并提供日志入口。
- 增加隔离诊断用户目录，首次启动验证不复用网站令牌、百应登录及工作台缓存。
- 百应原生工具栏提供“返回工作台”，未登录百应也可以先查看工作台及设置。

## 交付

桌面“鑫客主播工作台-0.3.3-分享包”与同名ZIP。0.3.2停止分发，保留目录并标记旧版勿用。普通分享包不含登录缓存、服务器凭据或发布私钥。

## 验证结果

- 四项安装回归全部通过：默认首次安装、升级保留关闭的自启、显式开启、显式取消。每项均验证7个外置文件的SHA-256、HTML资源引用及JS/CSS存在。
- 以新的隔离用户目录启动实际安装目录里的EXE，未复用任何网站令牌、百应会话和WebView缓存。百应登录页正常；点击返回工作台后，工作台页面、十项明细及网站登录表单均正常显示。
- 原生业务请求允许范围及服务器固定证书连接检查通过。
- 不为验证此问题登录测试账号或新增真实上报，不修改用户现有登录缓存。
