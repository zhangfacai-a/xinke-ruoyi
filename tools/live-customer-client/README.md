# 鑫客直播采集客户端

这是桌面安装版和 Chrome 快捷方式的源代码。推荐使用“首次安装”快捷方式在日常 Chrome 中手动加载一次插件，之后日常快捷方式直接打开主播后台。

首次安装插件：

1. 双击桌面的“鑫客采集插件（首次安装）”。
2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择安装目录下的 `chrome-extensions\douyin-live-customer-v2` 文件夹。
4. 看到“直播客户采集器 V2”后关闭页面。
5. 以后双击“鑫客直播采集客户端”即可运行。它使用你平时的 Chrome 登录状态。

启动器仍保留以下能力：

- 检查本机 Chrome 是否存在；
- 加载专用 Chrome 用户目录和 V2 插件；
- 启动前检查插件版本；
- 下载、校验、替换新版插件；
- 更新失败时保留旧插件并提示；
- 自动打开抖音主播后台。

构建需要 .NET 8 SDK。发布安装包还需要 Inno Setup 6。
