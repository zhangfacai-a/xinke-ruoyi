# 直播辅助工具

## 主播班次自动上报

- `launcher/`：开机自启的 Windows 托盘程序。
- `extensions/jinritemai-shift-report/`：巨量百应 DOM 采集插件，支持人工上报和自动任务。
- `scripts/build-live-metrics-agent.ps1`：生成包含插件的完整安装包。
- `直播数据自动采集-安装使用教程.md`：面向普通使用人员的教程。

## 直播客户插件

- `extensions/douyin-live-customer-v2/`：直播客户数据插件，和班次自动上报相互独立。
- `scripts/package-live-customer-plugin.ps1`：打包直播客户插件。
