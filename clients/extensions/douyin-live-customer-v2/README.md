# 直播客户采集器 V2

这是全新的 MV3 插件，与 `douyin-audience-rank` 旧版完全隔离。

## 安装

1. 先确认线上系统已启动（插件统一连接 `http://47.116.62.234/prod-api`），再打开直播运营系统 `http://47.116.62.234/`。
2. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开 `https://anchor.douyin.com/anchor/dashboard` 或 `https://anchor.douyin.com/anchor/analyze/audience_rank`，插件会自动显示悬浮窗并开始采集。

进入采集后插件会自动尝试激活页面上的“在线观众”页签；悬浮窗显示“在线观众已激活”后才会持续接收观看用户。若页面刚打开仍显示“正在激活”，保持当前页面即可，插件会自动重试。

## 悬浮窗

- 拖动悬浮窗顶部可以调整位置，刷新页面后会记住位置。
- 点击右上角减号可收纳成状态球，点击状态球重新展开。
- 状态球颜色代表当前状态：绿色采集中、橙色准备或同步中、灰色暂停、红色需要处理。
- 状态球右上角数字是尚未同步的数据量。
- “查看采集”用于核对插件实际识别的内容；“结束本场”会先尝试同步剩余数据，再暂停采集。

点击插件弹窗中的“查看采集”可以检查最近捕获的评论和观看用户。界面文案（如“互动评论”“设置”“暂无评论”“发送”）会被过滤，不会作为真实评论上传。

## 上传协议

插件内置 `config.js` 的线上 API 地址和版本密钥；员工无需手工填写地址或密钥。

采集事件首先写入 IndexedDB，断网或关闭标签页不会清除待同步数据。后台接口按 `eventId` 幂等，重复请求不会重复生成事件。
上传正文默认使用随机 AES-256-GCM 加密，再用服务端 RSA-OAEP 公钥封装 AES 密钥；每批使用新的密钥和随机向量，离线数据跨天也可以正常重试。服务端私钥只放在后端配置中，插件不会保存私钥。部署后端时设置 `LIVE_CRM_V2_RSA_PRIVATE_KEY_V3` 环境变量；未配置私钥时，加密批次会保留在本地队列，不会丢失。

## 采集频率

- 评论仅监听评论区域，每 20 秒做一次兜底扫描。
- 采集脚本只在抖音主播后台直播控制台 `/anchor/dashboard` 和观众分析页 `/anchor/analyze/audience_rank` 运行，其他页面不注入采集逻辑。
- 评论每 180 秒同步一次，待同步评论达到 60 条时立即同步。
- 观看用户名单变化时立即记录；名单不变时，每位仍在线用户每 180 秒发送一次轻量心跳，用于计算观看时长。完全相同的名单不会高频重复同步。
- 在线观众采用接口与 DOM 混合识别：接口负责可靠的 `sec_uid`，DOM 只负责判断名单是否变化。
- 在线观众变化后每 5 秒本地检查一次，稳定 30 秒后降为 20 秒，稳定 2 分钟后降为 60 秒；评论的 20 秒兜底不会额外扫描观众列表，这些检查也不会请求服务器。
- 每个直播场次最多自动切换一次观众页签，用于补抓页面打开前已经加载的观众身份，成功后不再自动操作页面。
- DOM 中只有昵称的用户先留在本机等待补全，不会作为缺少 `sec_uid` 的完整观看用户上传。
- 插件每 180 秒发送一次轻量心跳，手动“立即同步”不受定时策略限制。
- 每个插件会保存一个 0～30 秒的固定错峰时间，多个直播间不会在同一秒集中请求。
- 上传失败会按 1 分钟、2 分钟、5 分钟、10 分钟逐步退避；服务器繁忙时会自动稍后重试。
- 插件不设置单批 200 条业务上限，上传会按本地队列每 500 条一块发送；服务器按自身处理能力控制并发。
- 原始评论文本只保存在本机采集诊断中，不会上传到服务器。

## 远程更新

插件每天请求 `/open-api/v2/live/plugin/version`。服务器配置 `live.crm.v2.latest-version` 高于插件版本时，弹窗显示“有新版”。`update-url` 填写管理员发布的 ZIP 地址，`update-sha256` 填写 ZIP 的 SHA-256。

当前桌面启动器只负责用普通 Chrome 打开主播后台，不会自动加载或替换插件。使用 `chrome://extensions` 加载本目录时，版本更新需要替换插件文件并在扩展管理页点击“重新加载”。企业环境也可以使用 Chrome Web Store 或企业扩展管理策略。

## 防呆与异常保护

- 弹窗只把主播后台和观众分析页识别为直播采集页；在其他抖音后台页面会自动引导到主播控制台 `/anchor/dashboard?from=default`，并提供手动跳转按钮。
- 同步连续失败 3 次后自动熔断：停止当前页面采集、停止心跳和版本请求，并在插件中显示失败原因。修复地址或服务后点击“恢复监控”才会重新开始，避免旧版本或错误地址持续请求。
- 熔断只影响当前插件安装，不删除本机离线队列；恢复后会继续上传未同步数据。
