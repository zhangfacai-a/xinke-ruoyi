# 鑫客主播数据上报插件 5.0.12

只在主播本次直播结束时操作一次，不持续监听页面，也不自动上报。

## 操作流程

1. 打开当前场次的“直播大屏·专业版”。
2. 选择本次主播，点击“读取并核对”。
3. 核对插件突出展示的本次结果；“直播累计”仅作为辅助参考。
4. 点击“确认并上报 · 主播姓名”。
5. 完成页核对本次结果；如需继续，点击“继续上报”。

## 计算规则

- 本场第一次上报：开始时间使用页面开播时间，本次数据为当前累计值减 0。
- 本场后续上报：开始时间使用上一条上报时间，本次数据为当前累计值减上一条累计值。
- `live_room_id` 是场次唯一标识，不同场次的数据不会混算。
- 如果读取后有人先完成上报，当前提交会被拒绝，必须重新读取，避免重复分配数据。
- 平台累计值发生回调时保留真实负差额并标记为平台校正，使各段合计仍能还原最终累计。
- 所有必填指标只允许从顶部蓝色总览卡读取；隐藏字段必须重新勾选，不会从趋势区或商品区猜值。
- 核对页使用一行两项的蓝卡字段布局；百分比显示当前蓝卡原值和该上报区间重新计算的比例，不使用累计比例百分点差。

插件读取并展示观看、互动、粉丝、成交、GMV、千川消耗和预售订单数据。缺少蓝色卡片字段时不会上报，并明确提示需要勾选的字段。

界面使用主播熟悉的业务名称，每个指标使用独立小卡，桌面端一行三项、窄窗口自动两项；标题栏支持拖动面板。数据采集、区间计算和上报规则未改变。

版本：`5.0.12`（生产版）
